# 🌱 Site Sustentável

> Um projeto web focado na conscientização ambiental, trazendo dicas ecológicas práticas e destacando iniciativas para a preservação do nosso planeta.

---

## 💻 Sobre o Projeto

O **Site Sustentável** é uma plataforma informativa criada para inspirar hábitos ecológicos no dia a dia. Com um design limpo, intuitivo e responsivo, o site é dividido em seções que explicam o conceito de sustentabilidade, oferecem dicas práticas e apresentam projetos reais que fazem a diferença, como hortas comunitárias e reaproveitamento de água da chuva.

### 🔗 Telas do Projeto
* **Home (`index.html`):** Apresenta o conceito de sustentabilidade, lista dicas para uma vida mais verde e exibe os contatos.
* **Projetos (`pag-02.html`):** Galeria com foco em iniciativas de impacto positivo (coleta seletiva, consumo consciente, transportes sustentáveis e reaproveitamento de alimentos).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias:

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS3:** Estilização visual, uso de Flexbox/Grid e *Media Queries* para garantir a responsividade em dispositivos móveis.
* **Google Fonts:** Tipografia moderna utilizando a fonte *Inter*.

---

## 🎨 Funcionalidades e Destaques

* **Design Responsivo:** O layout se adapta perfeitamente a smartphones, tablets e desktops.
* **Efeitos Visuais (*Hover*):** Os *cards* de conteúdo possuem interações suaves de elevação quando o mouse passa por cima, melhorando a experiência do usuário.
* **Navegação Simples:** Menu claro e objetivo interligando as páginas do site.
* **Identidade Visual Temática:** Uso estratégico da paleta de cores focada em tons de verde (`#82c91e`, `#387b2d`) para refletir o tema ambiental.
